# جام جهانی فوتبال فارسی

یک برنامه وب تک‌صفحه‌ای برای جام جهانی فوتبال با زبان فارسی و طرح راست به چپ

## ویژگی‌ها

- **برنامه بازی‌ها**: نمایش تمام بازی‌ها بر اساس تاریخ با پرچم تیم‌ها
- **جدول رده‌بندی**: جدول گروه‌ها با امکان جستجوی ایران
- **نتایج زنده**: نمایش بازی‌های در جریان با به‌روزرسانی خودکار هر 60 ثانیه
- **شمارنده بازی بعدی**: شمارنده معکوس تا بازی بعدی تیم ملی ایران


## ساختار پروژه

```
worldcup-farsi/
├── index.html          # فایل اصلی برنامه
├── README.md           # فایل راهنما
└── worker/
    ├── index.js        # کد Cloudflare Worker
    ├── package.json    # وابستگی‌ها
    ├── wrangler.toml   # تنظیمات Wrangler
    └── README.md       # راهنمای Worker
```
